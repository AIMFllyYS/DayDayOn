# DayDayOn 更新日志

面向用户的更新说明。「我的 → 检查更新」弹窗里显示的就是这里比你当前版本新的几节。
每一节标题固定为 `## v<版本号> · <日期>`，版本号遵循 SemVer，最新的写在最上面。

## v0.1.18 · 2026-11-27

- **好友小窝「今日体重 / 今日心情 / 今日步数」只读详情页同步上线**：在好友小窝里，这三张指标卡片保持与本人页面一致的清爽外观，现在直接点击即可进入该好友的专属只读详情页（顶栏居中显示「`<好友昵称>`的体重/心情/步数详情」），完整查看好友近一年的统计图（含好友身高/BMI 与 TA 设定的步数参考虚线）及月度日历与历史记录，点返回键自动回到该好友小窝。
- **团团支持读取好友的体重 / 心情 / 步数**：现在可以直接问团团某位好友最近的步数、体重趋势、BMI 或心情变化，用来互相鼓励对比；同时严格保持只读安全边界，严禁替好友新增、修改或删除任何指标数据。
