# DayDayOn 更新日志

面向用户的更新说明。「我的 → 检查更新」弹窗里显示的就是这里比你当前版本新的几节。
每一节标题固定为 `## v<版本号> · <日期>`，版本号遵循 SemVer，最新的写在最上面。

## v0.1.10 · 2026-11-12

- **通知中心顶部双卡片防溢出与横向防滑修复**：修复「消息与通知」页面顶部「打卡房间与动态」「官方与系统通知」双卡片在小屏与长公告文案下宽度撑开、文字溢出及画面可左右滑动的问题。
- **智能上传「+ 系统文件 / 附件」直传 AI 识别彻底修复（含新版安卓安装包 v0.1.10）**：修复在「智能上传」左下角点击「+ 系统文件 / 附件」选中照片或文本文件后因动态文件列表重置未能发送给团团识别的问题，并新增安卓原生内存流系统文件桥接与文件头自动识别，兼容无后缀照片、HEIC / DNG 及 TXT / MD / CSV / HTML 文档。

## v0.1.9 · 2026-11-12

- **智能上传系统文件与附件直传修复（含新版安卓安装包 v0.1.9）**：在「智能上传」左下角点击「+ 系统文件 / 附件」选中任意图片或文本附件后，立即关闭面板并直传给团团识别，修复选文件后停留在空状态的问题。
- **「我的」页面多级分组与手机提醒通知升级**：重构「我的」为三大清晰分组与独立二级设置页（打卡与提醒、外观与陪伴、权限管理、数据与关于、账号与安全），去除工程化权限常量文案；开启「手机提醒」时自动检测通知权限，升级安卓精确唤醒闹钟与状态栏通知推送，并支持一键发送测试通知。
- **今日步数记录优化与主页宽卡排布**：优化安卓硬件计步器首次授权读取、当日重启累计与步数同步准确性，新增「记录今日步数」面板（支持一键同步传感器与手动填写快捷档位）；主页「今日步数」卡片等高横跨双列，消除右下角留白。
- **消息与通知全屏改版及官方公告模块**：消息中心与二级互动页全面改为无外框全屏社交布局，顶部独立展示「打卡房间与动态」与「官方与系统通知」，下方排布好友私聊；新增数据库级官方公告模块，随时发布版本与运营通知。

## v0.1.8 · 2026-11-11

- **底部相册严格按拍摄时间最新到最旧排列（含新版安卓安装包 v0.1.8）**：修复在打卡页打开「智能上传」与「智能拍照」选图抽屉时，云同步、相册移动或连拍照片顺序错乱的问题，统一按真实拍摄时间从最新到最旧稳定排列。
- **底部相册左上角新增相册文件夹选择菜单**：以相册目录菜单替换原「选择照片」入口并隐藏顶部辅助文案，左上角保留简洁相册图标；菜单首项固定为「全部」，按稳定顺序展示手机各相册目录，目录较多时在限定高度内独立滚动，不再撑高底部抽屉。
- **RAW（`.dng`）与 HEIC 照片解码加固**：升级安卓端图像解码管线，支持系统硬件解码、内嵌缩略图提取与自动方向校正。

## v0.1.7 · 2026-11-11

- **智能打卡切手动填写与连续记餐修复**：修复在「智能识别」页完成扫描后切回手动填写、切换板块或继续记录下一餐时偶发报错（`409`）无法保存的问题；手动填写与智能识别上下文严格隔离。
- **跨页打卡进度即时同步与防丢提醒**：在智能打卡页保存记录后返回常规打卡页立即展示最新餐次与进度；手动解析完成但尚未点击最终保存时，误点返回会贴心提醒确认。
- **悬浮团团/墩墩焦点与无障碍体验优化**：修复展开分析抽屉收起悬浮宠物时的焦点残留警告，并补齐键盘回车/空格唤起支持。

## v0.1.6 · 2026-11-11

- **安卓原生 0ms 开屏与首屏提速**：开屏动画迁移至安卓原生层首帧即刻呈现，网页水合完成后硬件加速平滑揭开，彻底解决开屏等待与掉帧卡顿。
- **应用内更新下载与自动安装闭环**：全面切换至自有服务器独立安装包目录高速直出（彻底移除 GitHub 下载外链），支持在应用页面实时查看下载进度、切入后台继续下载、完成后自动校验并调起系统安装（含安装权限自动引导与续装），并固化统一签名支持平滑覆盖安装。
- **落地页 `/welcome` 与退出登录流转修复**：退出登录与注销后统一返回落地介绍页，登录页新增返回介绍页入口，客户端内访问落地页自动展示当前安装状态。
- **双端选图边界与安卓流式缩略图相册**：网页端上传图片直接调用系统文件管理器多选；安卓客户端采用流式硬件缩略图与分页无限下滑相册，告别多选卡顿。
- **智能打卡页核心复用与 Agent 传图对话**：智能拍照识别后直接原地复用完整打卡表单、分析报告与庆祝弹窗；Agent 对话支持直接选择图片预览与多模态发送。
- **饮食三餐全天统一结算闭环**：早 / 午 / 晚餐记录齐备（3/3）后统一计算全天总分并弹出庆祝，减脂档低热量正餐正向加分、膳食纤维不扣分。

## v0.1.5 · 2026-11-09

- **饮食三餐智能识别与连续打卡修复**：按当前时间就近默认早 / 午 / 晚餐（加餐仅限手动选择），餐次切换条展示今日已打卡 `✓` 标记；连续智能拍照时自动顺延至下一未打卡正餐，修复第二次拍照仍落回早餐及跨餐次备注干扰的问题。
- **温和化家常饮食评分**：优化膳食纤维、蛋白质与 GI 加分阶梯，正常家常三餐（如包子配蛋奶、米饭配炒菜）顺畅达标（`1/3 → 2/3 → 3/3`），三餐打满或加餐后计算全天总分。
- **五大板块同日多次 / 单次读写体验统一**：运动支持同日多次拍照自动合并运动明细并识别距离与组数；学习在今日时长未达标时默认打开空白新时段供累加碎片学习；睡眠与自定义目标同日修改直接覆盖更新。
- **全局智能打卡跳转闭环**：在智能识别页完成打卡后，点「查看打卡详情」可直接跳到对应目标的打卡页与所记餐次。

## v0.1.4 · 2026-11-08

- 「我的 → 账号」新增**权限管理**（位于隐私说明与注销账号之间）：统一管理相机、相册、计步器与本地闹钟 4 项手机权限。
- **安卓安装包升级为原生模块版（壳 v0.1.3）**：智能拍照直接调起手机原生高清相机；智能上传改为微信式 1–9 张顺序多选相册（右上角可一键取消选择）；单次最多同时上传 2 张照片（默认展示首图并保存双路径）；打卡提醒可切换「应用内提醒 / 手机提醒（手机端原生组件）」，手机端每天定时弹系统通知。
- **主页新增「今日步数」卡**：看今天走了多少步、近 30 天走势和比上周多走多少；装新版 App 并开启「身体活动 / 计步器」权限后自动同步硬件计步，网页端固定显示 0 步、不报错。
- **打卡日改为凌晨 0 点刷新**：过了零点就算新的一天，不再按凌晨 4 点切分。
- **饮食裁判升级**：三餐按全天总分结算，空腹自动加分，加餐按同一天覆盖入库，跳过打卡也要核验；裁判和智能识别会优先参考你写的备注，减少误判。
- 打卡页直接读取当天数据，切换餐次不会再串数据。

## v0.1.2 · 2026-11-06

- **打卡页变成真正的整页**：手机上贴满屏幕；电脑上左边填写、右边看分析。
- 打卡结果弹窗里的「完成」只收起弹窗，不会再把你带回主页。
- **全局只有一个团团（墩墩）**：打卡页不再出现第二只，分析中 / 已完成的小圆点挂在悬浮的它身上，点它就能展开分析。

- 本周热力图分出「打了没达标」，和「没打」不再混在一起。
- 问团团「这周各板块怎么样」，对话里会直接弹出同款近况卡。
