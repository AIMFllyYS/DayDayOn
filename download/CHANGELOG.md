# DayDayOn 更新日志

面向用户的更新说明。「我的 → 检查更新」弹窗里显示的就是这里比你当前版本新的几节。
每一节标题固定为 `## v<版本号> · <日期>`，版本号遵循 SemVer，最新的写在最上面。

## v0.1.4 · 2026-11-08

- 「我的 → 账号」新增**权限管理**（位于隐私说明与注销账号之间）：统一管理相机、相册、计步器与本地闹钟 4 项手机权限。
- **安卓安装包升级为原生模块版（壳 v0.1.3）**：智能拍照直接调起手机原生高清相机；智能上传改为微信式 1–9 张顺序多选相册（右上角可一键取消选择）；单次最多同时上传 2 张照片（默认展示首图并保存双路径）；打卡提醒可切换「应用内提醒 / 手机提醒（手机端原生组件）」，手机端每天定时弹系统通知。
- **主页新增「今日步数」卡**：看今天走了多少步、近 30 天走势和比上周多走多少；装新版 App 并开启「身体活动 / 计步器」权限后自动同步硬件计步，网页端固定显示 0 步、不报错。
- **打卡日改为凌晨 0 点刷新**：过了零点就算新的一天，不再按凌晨 4 点切分。
- **饮食裁判升级**：三餐按全天总分结算，空腹自动加分，加餐按同一天覆盖入库，跳过打卡也要核验；裁判和智能识别会优先参考你写的备注，减少误判。
- 打卡页直接读取当天数据，切换餐次不会再串数据。

## v0.1.3 · 2026-11-06

- 「我的 → 账号」新增**检查更新**：已经是最新时会提示一声；有新版本时弹出这份更新说明，网页版点「刷新」就能用上，App 有新安装包时点「下载安装包」。
- App 安装包改从 DayDayOn 自己的服务器下载，国内打开更稳；GitHub Release 保留作备用。

## v0.1.2 · 2026-11-06

- **打卡页变成真正的整页**：手机上贴满屏幕；电脑上左边填写、右边看分析。
- 打卡结果弹窗里的「完成」只收起弹窗，不会再把你带回主页。
- **全局只有一个团团（墩墩）**：打卡页不再出现第二只，分析中 / 已完成的小圆点挂在悬浮的它身上，点它就能展开分析。
- 「提交并 Agent 自动解析」会新开一段对话来分析，过程和结论都存进对话历史，还能在里面接着追问。
- 主页新增**各板块近况**：每个目标一张小卡，看平均分 / 时长 / 入睡时刻、达标率和最近走势，还会告诉你最常卡在哪条规则。
- 本周热力图分出「打了没达标」，和「没打」不再混在一起。
- 问团团「这周各板块怎么样」，对话里会直接弹出同款近况卡。

## v0.1.1 · 2026-11-05

- 五大打卡板块接入 Agent 裁判：按你的达标规则判定，未达标的打卡照常存档，但不计进度、连续天数和排行。
- 和团团对话就能记打卡、改今天和昨天的打卡、删打卡、查改动记录。

## v0.1.0 · 2026-11-04

- 首个正式版：全板块智能拍照 / 上传打卡，Android 安装包首发。
