# scripts/

辅助脚本。

| 目录 | 用途 |
|---|---|
| [`setup/`](./setup/) | 环境初始化、配置生成 |
| [`build/`](./build/) | 构建辅助、standalone 制品组装与检查 |
| [`deploy/`](./deploy/) | 部署辅助（服务器侧闸门脚本的仓库副本、发布检查） |
| [`dev/`](./dev/) | 开发辅助、mock 数据、调试脚本 |

## 脚本规范

- Shell 脚本用 `.sh`，Node 脚本用 `.mjs` 或 `.ts`；文件名用 kebab-case
- 脚本开头注释说明用途、参数、退出码含义
- 危险操作（删除、覆盖、改服务器）前必须确认
- 脚本里不写任何密钥，从环境变量读取
