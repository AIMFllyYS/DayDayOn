需要新增的依赖

前端（进客户端包）：@base-ui/react、react-day-picker、date-fns、@date-fns/tz、d3-shape、@tanstack/react-query、zod。

服务端：better-auth、drizzle-orm、pg、hono、@hono/zod-openapi、nodemailer，以及已由负责人指定的 ai、@ai-sdk/deepseek、@ai-sdk/react。

开发：drizzle-kit、vitest、vite、@types/pg（Nodemailer 10 自带类型，不装 @types/nodemailer）。

明确不引入：动效库、表单库、图表库、图片压缩库、Service Worker 工具库、任务队列、tailwind-merge。

已由负责人指定的所有者

  • AI：Vercel AI SDK（ai 7.0.159、@ai-sdk/deepseek 3.0.77、@ai-sdk/react 4.0.163），模型只用 deepseek-flash。AI SDK 文档说明：直接写字符串模型 id 时默认走 Vercel AI Gateway，所以必须用 deepSeek('deepseek-flash') 这种 provider 实例，不能写字符串。
  • 图标、吉祥物：自研（ui-design-system.md 第 6、9 节）。

方法

  • registry：registry.npmjs.org 完整 packument：latest 版本、发布时间、12 个月内发布次数、维护者数、许可证、直接依赖、peer 依赖、安装脚本
  • downloads：api.npmjs.org/downloads/point/last-week（部分包被限流，值为 null 表示未取到）
  • github：gh api repos/<owner>/<repo>：stars、最近 push、是否归档
  • transitive：在临时目录用 pnpm 11.7 安装候选后，沿 dependencies / optionalDependencies 遍历 node_modules，统计传递依赖数、copyleft 许可证、preinstall / install / postinstall 脚本（不含 peer 依赖）
  • size：在临时目录用 esbuild 按本项目实际会用到的导出组合打包，minify，react / react-dom 外置，gzip -9；数值单位 KB。不同用例之间共享代码，单项相加会高估
  • bundlephobia：bundlephobia.com/api/size：整包 min+gzip（不做 tree-shaking），只在没有实测用例时参考
