关注点 14 · C 业务基础设施 · ADR-0017

SMTP 发信

通用 SMTP 客户端，而不是云厂商 SDK。

我们需要什么

  • 登录验证码邮件
  • 额度异常告警邮件（发给管理员）
  • 阿里云邮件推送，SMTP 465（ADR-0002 第 2 节）

候选

Nodemailer

推荐nodemailer

  • 0 个依赖，MIT-0 许可证
  • SMTP 密码只对一个发信地址有效，权限小
最近发布10.3.1（2026-10-29；12 个月内 53 次）

  • 2026 年修复过地址解析和 SMTP 回复解析的漏洞（CVE-2026-110870、CVE-2026-110872，分别在 10.0.13、10.0.10 修复），版本至少用 10.3.1

适合我们吗：最直接。

决定

所有者：Nodemailer，版本 10.3.1

封装层入口：src/server/mail/（transport、模板、sendOtp()、sendAlert()）

  • 邮件模板用简单 HTML 字符串，不引入模板引擎
  • 收件地址先过白名单校验再交给 Nodemailer

放弃了什么：

  • 阿里云 SDK：需要高权限 AccessKey
