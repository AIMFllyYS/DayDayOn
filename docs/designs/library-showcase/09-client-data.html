关注点 9 · C 业务基础设施 · ADR-0012

客户端数据请求

首屏用 RSC；交互后的读写用一个客户端缓存库。只用 RSC + router.refresh() 做不到乐观更新和局部回滚。

我们需要什么

  • 首屏数据由 Server Component 直接调 service 输出
  • 打卡、待办勾选：先更新界面，失败回滚
  • 写入后刷新相关列表和统计
  • AI 识别过程中轮询或流式更新状态

决定

所有者：TanStack Query，版本 5.105.0

封装层入口：src/lib/api/（QueryClient、类型化的接口客户端、query key 工厂）

  • query key 统一由 src/lib/api/keys.ts 生成
  • 业务组件不直接 fetch /api/v1，一律经 src/lib/api/

放弃了什么：

  • SWR：写入与回滚工具较少
  • 只用 RSC：没有乐观更新

已知代价：客户端多约 10 KB。

何时重审：

  • 做离线草稿（v0.2）时评估持久化方案
