关注点 12 · C 业务基础设施 · ADR-0015

数据访问

SQL 风格的 ORM + 迁移工具；数据库驱动单独选。

我们需要什么

  • PostgreSQL 18（服务器 127.0.0.1:23432）
  • TypeScript 写 schema，生成可审阅的 SQL 迁移文件
  • 事务和原子更新（额度预占与结算）
  • Better Auth 适配器

候选

Drizzle ORM 0.45 + drizzle-kit

推荐drizzle-orm

npm 描述："Drizzle ORM package for SQL databases"

  • drizzle-orm 0 个依赖
  • drizzle-kit generate 生成 SQL 迁移
  • Better Auth 的 peer 依赖接受 drizzle-orm ^0.45.2 或 1.0 RC
最近发布0.45.4（2026-10-08；12 个月内 281 次）
维护npm 维护者账号 4 个；GitHub ★36,187，最近提交 2026-10-30
体积服务端运行，不进客户端包（npm 解包 10.0 MB）；直接依赖 0 个，传递依赖 0 个
安装脚本包本身与传递依赖都没有 preinstall / install / postinstall
许可证Apache-2.0；依赖树无 copyleft
兼容性peer：pg >=8
类型包内自带类型声明
  • 1.0 正处于 RC（rc.5），npm latest 仍是 0.45.x；官方提供 drizzle-kit up 升级
  • drizzle-kit（开发依赖）会带进 3 个版本的 esbuild，都有 postinstall 脚本（本次扫描）

适合我们吗：和需求最贴合，运行时零依赖。

数据库驱动

  • pg（node-postgres）8.23：选用：Better Auth peer 支持 pg，以后的 pg-boss 也用 pg，全项目只有一个驱动
  • postgres（postgres.js）4.0.0：不用：4.0.0 是 2026-10-30 刚发布的大版本

决定

所有者：Drizzle ORM + drizzle-kit + pg，版本 drizzle-orm 0.45.4、drizzle-kit 0.31.11、pg 8.23.1

封装层入口：src/server/db/（client.ts、schema/<领域>.ts、migrations/）；只有 src/server/ 可以 import drizzle-orm 和 pg

  • 迁移用 drizzle-kit generate 生成并提交，PR 里审 SQL；生产环境不用 push
  • Better Auth 的表用 npx auth generate 生成到 Drizzle schema

放弃了什么：

  • Drizzle 1.0 RC：生产不用 RC
  • Prisma：latest 指向 RC
  • Kysely：没有迁移生成

已知代价：1.0 稳定后需要升级一次（drizzle-kit up）。

何时重审：

  • Drizzle 1.0 发布稳定版时
