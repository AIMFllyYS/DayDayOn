# ADR-0021：头像——只用预设头像，不支持上传

- 状态：Accepted <!-- 被推翻时改为 Superseded by ADR-XXXX，正文不改 -->
- 日期：2026-10-31（负责人在 Phase 3 功能盘点时确认方案 A）
- 决策人：项目负责人（AI 提供分析）

## 背景

- 新人引导要设置昵称和头像（ADR-0003 MVP 第 1 项）。
- 用户图片永不落盘、不上云（ADR-0002 第 4 节）。
- 头像会出现在公开排行榜上；用户上传的头像在国内上线需要内容审核。

## 面临的选项

- A 预设头像：团团的不同表情 × 板块配色，昵称首字兜底。
- B 允许上传头像，作为"图片不落盘"的唯一例外：需要存储、裁剪组件和内容审核。
- C 只用昵称首字 + 颜色。

## 决定

采用 A。

- 头像在数据库里只存预设的标识（例如 `mascot:cheer:exercise`），不存图片。
- 没有选择时显示昵称首字 + 颜色（现有 `Avatar` 组件）。
- 预设头像的绘制复用 `src/components/mascot/`，在 Playbook 里登记。

## 理由

- 不破坏"图片不落盘"，也不需要存储和裁剪。
- 不需要内容审核。
- 团团本来就是产品形象，预设头像也能统一治愈风格。

## 放弃了什么

- 用户无法用自己的照片作头像。

## 何时重审

- 用户普遍要求上传头像时（需要同时决定存储位置和内容审核方案）。
