# ADR-0017：SMTP 发信——Nodemailer

- 状态：Accepted（负责人 2026-10-31 拍板：Phase 3 的 17 项建议全部采纳）
- 日期：2026-10-31
- 决策人：项目负责人（AI 提供分析）
- 对比页：[docs/designs/library-showcase/14-smtp.html](../designs/library-showcase/14-smtp.html)

## 背景

- 登录验证码邮件
- 额度异常告警邮件（发给管理员）
- 阿里云邮件推送，SMTP 465（ADR-0002 第 2 节）

先定的层：通用 SMTP 客户端，而不是云厂商 SDK。

## 面临的选项

- **Nodemailer**（`nodemailer`）：推荐。最直接。
- **阿里云邮件推送 SDK**（`@alicloud/dm20151123`）：不采用。多一份高权限密钥。

## 决定

Nodemailer，版本 10.3.1。

- 封装层入口：src/server/mail/（transport、模板、sendOtp()、sendAlert()）
- 邮件模板用简单 HTML 字符串，不引入模板引擎
- 收件地址先过白名单校验再交给 Nodemailer

## 理由

最直接。

- 0 个依赖，MIT-0 许可证
- SMTP 密码只对一个发信地址有效，权限小

## 放弃了什么

- 阿里云 SDK：需要高权限 AccessKey
